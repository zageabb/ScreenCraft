# Standards adoption — ScreenCraft-specific applicability
1. P6 design tooling/P3 specialist editor rather than P1 enterprise application.
2. Flask and JavaScript editor are allowed; React/MUI/FastAPI P1 preference is not mandatory.
3. Absolute coordinates are legitimate within an explicit design canvas, but not arbitrary application chrome.
4. No requirement for Entra, Power BI or other enterprise integration; optional adapters explicitly support not_configured.
5. Source's private corporate screen samples and draft brand references are NOT copied to this public repository.
No exemption is granted from security, accessibility, evidence and test requirements. Record future exceptions via ADR.
